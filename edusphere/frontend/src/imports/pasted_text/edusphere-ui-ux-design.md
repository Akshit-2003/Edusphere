Design a complete high-fidelity UI/UX design for a modern AI-powered collaborative learning platform called:

"EduSphere"

Tagline:
"Learn. Collaborate. Organize. Master."

The product is a modern web application combining:
- LMS
- Notion-style study workspace
- Google Docs-style real-time collaboration
- Kanban study planner
- Flashcards with spaced repetition
- Quiz and assessment system
- Classroom and group chat
- AI study assistant
- PDF-to-study-material generation
- Interactive knowledge graph
- Semantic search
- Personalized learning analytics

The design must look like a premium modern SaaS/productivity application rather than a traditional college LMS.

==================================================
DESIGN DIRECTION
==================================================

Create a clean, premium, minimal and highly polished interface.

Visual inspiration:
- Modern productivity SaaS
- Notion-like workspace
- Linear-like dashboard
- Modern AI products
- Professional education platforms

Do NOT copy any existing product.

Design language:
- Minimal
- Elegant
- Modern
- Professional
- Academic
- AI-focused
- Productivity-oriented

Use generous whitespace, clean cards, subtle borders, soft shadows and excellent typography.

Avoid:
- Old-fashioned LMS appearance
- Excessive gradients
- Overly colorful UI
- Cluttered dashboards
- Excessive glassmorphism
- Cartoon-style education graphics
